# TgApteka: Telegram Bot for Medicine and Pharmacy Assistance

## О проекте

Я разработал TgApteka как Telegram-бота, который помогает пользователям искать информацию о лекарствах, просматривать данные о препаратах и получать рекомендации по аптечным услугам. Бот ориентирован на удобный доступ к медицинской информации прямо в чате, с использованием встроенных баз данных для быстрого поиска. Он обрабатывает запросы на поиск лекарств по названию, показывает детали (дозировки, показания, противопоказания) и может генерировать отчеты по аптечным данным.

Этот проект создан для упрощения повседневных задач, связанных с медициной, и может быть полезен студентам, врачам или обычным пользователям, нуждающимся в быстром справочнике.

## Технологии

- **Python** 3.10+ (основной язык разработки)
- **python-telegram-bot** (библиотека для интеграции с Telegram API)
- **python-dotenv** (управление переменными окружения, включая BOT_TOKEN)
- **zipfile** и другие стандартные библиотеки (для работы с архивами баз данных)
- **logging** (логирование событий и ошибок)

Все зависимости указаны в requirements.txt, включая необходимые пакеты для Telegram-интеграции и обработки данных.

## Основной функционал

- **Поиск лекарств:** Пользователи вводят название препарата, бот извлекает данные из MedicineDatabase_.zip и возвращает информацию (название, дозировка, показания).
- **Аптечные отчеты:** Доступ к данным из PharmacyDBR.zip для генерации отчетов о наличии, ценах или рекомендациях.
- **Команды бота:** 
  - /start: Приветствие и инициализация.
  - /search <название>: Поиск по базе лекарств.
  - /help: Список доступных команд.
- **Обработка сообщений:** Текстовые запросы парсятся для поиска в базах данных.
- **Inline-режим:** Поддержка inline-запросов для быстрого поиска без открытия чата.
- **Ошибка и валидация:** Бот обрабатывает неверные запросы, сетевые ошибки и проблемы с файлами через try-except блоки.
- **Хранение данных:** Базы данных хранятся в ZIP-архивах (MedicineDatabase_.zip для справочника лекарств, PharmacyDBR.zip для аптечных отчетов), которые распаковываются и читаются при необходимости.

## Быстрый старт

### 1. Клонируем репозиторий
```bash
git clone https://github.com/Emil-BAD/TgApteka.git
cd TgApteka
```

### 2. Создаём и активируем виртуальное окружение
```bash
python -m venv venv
```

- **Windows:**
```bash
venv\Scripts\activate
```

- **Linux/macOS:**
```bash
source venv/bin/activate
```

### 3. Устанавливаем зависимости
```bash
pip install -r requirements.txt
```

### 4. Настраиваем .env
Создайте файл `.env` с вашим Telegram BOT_TOKEN:
```
BOT_TOKEN=your_bot_token_here
```

(Получите токен от @BotFather в Telegram.)

### 5. Запускаем бота
```bash
python app.py
```

Бот запустится в режиме polling и будет готов к взаимодействию.

## Примеры использования

- **/start:** Бот приветствует пользователя и предлагает начать поиск.
- **/search aspirin:** Возвращает информацию о аспирине из базы (дозировка, применение).
- Текстовый запрос: "Найди парацетамол" — бот парсит и отвечает данными из MedicineDatabase_.
- В inline-режиме: @TgAptekaBot ibuprofen — быстрый поиск в любом чате.

Для тестирования используйте test.py, который симулирует запросы и проверяет логику.
